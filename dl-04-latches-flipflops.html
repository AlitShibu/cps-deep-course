Latches & Flip-Flops

Every circuit in Chapter 3 was combinational — its output depended only on its current inputs, with zero memory of the past. This chapter introduces the single idea that changes everything: feedback. A gate whose output loops back into its own input can hold a value even after the input that set it disappears — the literal foundation of every register, counter, and memory cell in your CPS work.

Section 4.1

Why combinational logic alone can't remember anything

Every circuit from Chapter 3 — adders, multiplexers, decoders — computes its output instantly and purely from its current inputs. The moment an input changes, the output changes to match, with no trace of what the inputs used to be. This is a real limitation: a counter needs to remember "what number was I at last," a register needs to hold a value steady while other parts of a circuit do something else — neither is possible with purely combinational logic.

The one idea that fixes this: feedback

If a gate's output is wired back around into one of its own inputs, the circuit's current output starts influencing its own future output — creating a loop where the circuit can, in effect, "remember" a decision it made a moment ago. This single idea — feedback — is the entire foundation of every memory element in this chapter, from the simplest latch to the flip-flops that build every register and counter in Chapters 5-6.

Section 4.2

The SR latch — the simplest possible memory circuit

Cross-couple two NOR gates — each gate's output feeds into the other gate's input — and you get an SR latch (Set-Reset latch), the most basic memory element in digital logic.

Each gate's output feeds back into the other gate's second input — the cross-coupling that creates memory.
SRBehavior
00Hold — Q keeps whatever value it already had (the memory effect)
10Set — Q becomes 1
01Reset — Q becomes 0
11Forbidden — produces an undefined/unstable result, avoid entirely
Where the memory actually comes from

When both S and R are 0, neither gate is being forced to a particular output by its "fresh" input — each gate's output is determined entirely by the other gate's current (fed-back) output. This is a genuine, self-sustaining loop: Q stays whatever it was, because the circuit has no other information available to change it. This "hold" state — persisting a value using nothing but the circuit's own feedback, with no active input demanding a specific value — is the literal definition of digital memory, and every more complex memory element in this course builds on exactly this mechanism.

Why S=1, R=1 is forbidden

Forcing both outputs to specific values simultaneously (both gates try to force Q=0 and Q'=0 at once) breaks the intended Q/Q' complementary relationship (Q' should always be the opposite of Q) — and worse, if S and R are released back to 0 at exactly the same instant, which gate "wins" the resulting hold state becomes a race determined by microscopic manufacturing differences between the two gates, not by any input you controlled. Real circuit designs must guarantee this input combination never occurs.

Section 4.3

The D latch, and the crucial jump to edge-triggered flip-flops

The D latch — fixing SR's forbidden state

An SR latch's forbidden state (Section 4.2) is a real design hazard — better to make it structurally impossible. A D latch (Data latch) adds a small amount of extra logic ensuring S and R are always opposite of each other, controlled by a single "D" (data) input and an "Enable" signal:

Enable | Behavior
  0    | Hold -- Q keeps its current value, ignoring D entirely
  1    | Q follows D directly -- whatever D is, Q immediately becomes
The D latch's real limitation: transparency

While Enable=1, the D latch is transparent — Q tracks D continuously and instantly, not just once. If D happens to be changing rapidly while Enable is 1 (electrical noise, a fast-changing signal), Q changes right along with it — the latch doesn't capture one specific value, it just mirrors whatever D is doing for the entire time Enable is high. For building reliable, predictable multi-stage circuits (Chapters 5-6's counters and registers), you need something that captures a value at one precise instant, not a whole window of time.

The edge-triggered D flip-flop — capturing one precise instant

A flip-flop (as opposed to a latch) only updates its output at the exact moment a clock signal transitions — typically the rising edge (low-to-high transition), not during the entire time the clock is high. This single change — reacting to an edge (an instant) rather than a level (a duration) — is what makes flip-flops the standard building block for reliable sequential circuits.

A flip-flop only "looks at" D at the instant of the rising edge — everything D does between edges is irrelevant.
Why edge-triggering is essential for building anything bigger than one memory cell

Chapter 5's counters and registers chain many flip-flops together, often with one flip-flop's output feeding into the next's input. If every element were level-triggered (transparent while enabled, like the D latch), a change could "ripple" through several connected stages within a single clock pulse — an uncontrolled, unpredictable cascade. Edge-triggering guarantees every flip-flop in a large circuit updates at the exact same, precise instant (the clock edge), and only then — making the behavior of arbitrarily large, complex sequential circuits fully predictable and analyzable, which is the entire reason real digital systems are built almost exclusively from edge-triggered flip-flops, not level-triggered latches.

Setup and hold time — a real, practical constraint

A real flip-flop needs D to be stable for a small window of time before the clock edge (setup time) and after it (hold time) to reliably capture the correct value — this isn't a theoretical nicety, it's a genuine electrical requirement listed on every real flip-flop's datasheet, in nanoseconds. Violating setup/hold time can cause metastability — the flip-flop settling into neither a clean 0 nor 1, an unpredictable, genuinely dangerous failure mode in real hardware design, especially at high clock speeds.

Section 4.4

Worked problem — tracing a flip-flop through several clock cycles

Problem

A D flip-flop starts at Q=0. On each rising clock edge, D has the following value: edge 1: D=1, edge 2: D=1, edge 3: D=0, edge 4: D=1. What is Q after each edge?

Before any edge:  Q = 0

Edge 1 (D=1): Q captures D's value at this instant -> Q becomes 1
Edge 2 (D=1): Q captures D again -> Q stays 1 (no change, since D was already 1)
Edge 3 (D=0): Q captures D -> Q becomes 0
Edge 4 (D=1): Q captures D -> Q becomes 1

Final: Q = 1, having been: 0 -> 1 -> 1 -> 0 -> 1

Why this is straightforward once edge-triggering clicks: Q only ever changes value at a rising edge, and always to exactly whatever D was at that precise instant — nothing that happens to D between edges matters at all. This is precisely why a timing diagram (Section 4.3's diagram) only needs to mark the clock's rising edges to fully predict Q's entire behavior.

Wrap-up

Recap

  1. Feedback — a gate's output looping back into its own input — is the single mechanism that lets a circuit remember a value, something pure combinational logic (Chapter 3) can never do.
  2. An SR latch (cross-coupled NOR gates) is the simplest memory element — it holds Q when S=R=0, but has a forbidden S=R=1 state that real designs must avoid.
  3. A D latch fixes the forbidden-state problem but is transparent while enabled — Q continuously tracks D, which is unreliable for chaining multiple memory stages together.
  4. A flip-flop is edge-triggered — it only captures D's value at the instant of a clock edge, making large, multi-stage sequential circuits fully predictable, which is why flip-flops (not latches) are the standard building block for real digital systems.
  5. Setup and hold time are real electrical constraints on how stable D must be around a clock edge — violating them risks metastability, a genuine hardware failure mode.
Check yourself

Quick check

Question 1

What single mechanism allows a digital circuit to have memory, when Chapter 3's combinational circuits cannot?

Feedback -- wiring a gate's output back into its own (or another gate's) input, creating a self-sustaining loop that can hold a value without needing continuous input to maintain it.
Question 2

Why is a D latch's "transparency" a problem for building larger sequential circuits, even though it correctly stores D's value?

While Enable is high, Q continuously tracks any changes in D in real time, rather than capturing one specific value. If multiple such latches were chained together, a change could ripple through several stages uncontrollably within a single enable pulse, making large circuits built from latches unpredictable.
Question 3

A D flip-flop has Q=1. D changes several times between clock edges but is 0 at the moment of the next rising edge. What is Q immediately after that edge?

Q becomes 0 -- an edge-triggered flip-flop only cares about D's value at the precise instant of the clock edge; everything D did between edges is irrelevant.

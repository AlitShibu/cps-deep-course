Op-Amps & Basic Amplifier Circuits

An operational amplifier (op-amp) is a single integrated-circuit component that, combined with just a few resistors, can amplify a signal, compare two voltages, buffer a signal, or perform basic mathematical operations on it. This chapter builds the standard "ideal op-amp" model used for hand analysis, then applies it to the handful of configurations that account for the overwhelming majority of real op-amp circuits — genuinely useful for conditioning a sensor's small output signal before it reaches a microcontroller's ADC input.

Section 6.1

The ideal op-amp model

An op-amp has two inputs — the non-inverting input (+) and the inverting input (−) — and one output. Internally it's a complex multi-transistor circuit (built from exactly the BJTs and current-mirror structures introduced in Chapter 5), but for hand analysis, a simplified ideal model with two rules is almost always sufficient.

The two golden rules of ideal op-amp analysis

Rule 1: the output does whatever is necessary to make the voltage at the two inputs equal (this only holds when negative feedback — a path from output back to the inverting input — is present, covered next). Rule 2: no current flows into either input terminal (the inputs have essentially infinite input impedance). Nearly every op-amp circuit in this chapter is solved by applying just these two rules and then falling back on Ohm's Law and KCL from Chapters 1–2 — nothing more exotic is needed for basic configurations.

Open-loop gain and negative feedback

Without any feedback, an op-amp's open-loop gain is enormous (often 100,000× or more) — so large that even a tiny input voltage difference drives the output to its supply-voltage limit almost instantly. This makes an op-amp useless as a precise linear amplifier without feedback; it's negative feedback — feeding a portion of the output back into the inverting input — that tames this huge gain into a stable, predictable, and precisely controllable amount, set by external resistor values rather than by the op-amp's own (imprecise, temperature-sensitive) internal gain.

Section 6.2

Inverting and non-inverting amplifiers

Inverting amplifier

Feedback resistor R_f connects output back to the inverting (−) input; the non-inverting (+) input is grounded.
V_out = −(R_f / R_in) × V_in

  Gain = −(R_f / R_in)   -- negative sign means the output is INVERTED relative to input
Deriving the inverting amp gain from the two golden rules

Rule 1 forces the inverting input to sit at the same voltage as the grounded non-inverting input — 0V, called a "virtual ground." Rule 2 means no current flows into the input itself, so all the current arriving through R_in from V_in must instead flow entirely through R_f toward the output (KCL at that node — the same conservation idea from Chapter 2). Since the input side of R_in sits at V_in and the far side sits at virtual ground (0V), that current is V_in/R_in. That same current flowing through R_f, from virtual ground toward V_out, means V_out = 0 − (current × R_f) = −(V_in/R_in)×R_f — directly producing the gain formula above, from nothing more than the two golden rules and Ohm's Law.

Non-inverting amplifier

V_out = (1 + R_f/R_in) × V_in

  Gain = 1 + (R_f / R_in)   -- always positive, always ≥ 1, output is IN PHASE with input
Non-inverting gain can never be less than 1 — inverting gain can

The "+1" in the non-inverting formula means this configuration can only amplify or leave a signal unchanged, never attenuate it below its original amplitude — useful to remember when a design specifically calls for a gain less than one (which the inverting configuration, with R_f smaller than R_in, can provide directly). Confusing which configuration to reach for based on a target gain value is a common early design mistake.

The voltage follower (buffer)

Setting R_f=0 and removing R_in entirely in the non-inverting configuration gives gain exactly 1 — the output simply follows the input voltage. This seems pointless until you remember Rule 2: the op-amp's input draws essentially no current, while its output can supply meaningful current. A voltage follower isolates a delicate, high-impedance signal source (many sensors) from a load that would otherwise draw enough current to distort the source's own voltage — a genuinely common and important use, despite having "no gain" in the usual sense.

Section 6.3

The comparator: op-amps without feedback

Deliberately removing negative feedback and instead applying the enormous open-loop gain directly turns an op-amp into a comparator: the output swings to one supply rail if V+ > V−, and the opposite rail if V+ < V−, with no intermediate values.

if V(+) > V(−):  V_out = +supply rail (e.g. +5V, "HIGH")
if V(+) < V(−):  V_out = −supply rail or 0V (e.g. "LOW")
A comparator turns an analog signal into a digital one

This is exactly the analog-to-digital boundary: a comparator with one input tied to a fixed reference voltage produces a clean digital HIGH/LOW output depending on whether a sensor's analog signal crosses that threshold — precisely the kind of circuit that connects the analog world of Chapters 1-6 to the digital logic world of the earlier Digital Logic Design topic. A simple threshold-triggered alarm circuit (e.g. "turn on an LED once temperature exceeds X") is a direct, practical comparator application.

Section 6.4

Worked problem — amplifying a small sensor signal

Problem

A sensor outputs a small signal ranging from 0 to 0.5V, but a microcontroller's ADC reads most accurately across its full 0-5V input range. Design a non-inverting amplifier to scale the signal up by a factor of 10.

# Target: Gain = 10
# Non-inverting gain formula: Gain = 1 + (R_f / R_in)

10 = 1 + (R_f / R_in)
9 = R_f / R_in

# Choose a convenient, commonly available R_in, then compute R_f
R_in = 1 kΩ
R_f = 9 × R_in = 9 kΩ   -- (a standard 9.1kΩ resistor is close enough in practice)

# Check: V_out = (1 + 9000/1000) × 0.5V = 10 × 0.5V = 5V  ✓ (fits the ADC's full range)

Why R_in was freely chosen: only the ratio R_f/R_in determines the gain, not the absolute resistor values — this leaves a designer free to pick convenient, standard resistor values (as long as they're not so small as to draw excessive current, or so large as to be sensitive to noise) while still hitting the exact target ratio, the same underlying idea as the divider ratios from Chapter 2.

Why non-inverting rather than inverting was the right choice here: a gain of exactly 10 with no inversion is trivially matched by the non-inverting formula's clean "1 + ratio" form, and preserving the original sign relationship (higher sensor signal → higher ADC reading) is what you'd normally want for straightforward sensor conditioning, rather than an inverted output the microcontroller code would then need to un-invert.

Wrap-up

Recap

  1. The ideal op-amp model: with negative feedback, the output forces both inputs to the same voltage (Rule 1), and no current flows into either input (Rule 2). These two rules, plus Ohm's Law and KCL, solve nearly all basic op-amp circuits.
  2. Huge open-loop gain alone makes an op-amp unusable as a precise amplifier; negative feedback tames it into a stable, resistor-set gain.
  3. Inverting amp: Gain = −R_f/R_in (inverted, can be <1). Non-inverting amp: Gain = 1+R_f/R_in (in phase, always ≥1). Only the resistor ratio sets the gain — absolute values are a free design choice.
  4. A voltage follower (gain=1) isolates a delicate signal source from a current-hungry load, exploiting the op-amp's near-zero input current.
  5. A comparator is an op-amp deliberately run without feedback, using its huge open-loop gain to produce a clean digital HIGH/LOW output based on which input is larger — the practical bridge from analog signals to digital logic.
Check yourself

Quick check

Question 1

Why is negative feedback necessary for an op-amp to work as a stable, precise linear amplifier?

An op-amp's open-loop gain is enormous (100,000x or more) -- without feedback, even a tiny input difference drives the output immediately to its supply rail, making it useless for controlled amplification. Negative feedback tames this huge, imprecise internal gain into a stable amount set precisely by external resistor values instead.
Question 2

In an inverting amplifier, why does all the current arriving through R_in have to flow through R_f?

Rule 2 (ideal op-amp) says no current flows into the input terminal itself. By KCL, whatever current arrives at that node through R_in has nowhere else to go except through R_f toward the output -- there is no third path for it to take.
Question 3

Why is a voltage follower (gain = 1) still a useful circuit, even though it doesn't amplify anything?

A voltage follower's input draws essentially no current (Rule 2) while its output can supply meaningful current to a load. This lets it isolate a delicate, high-impedance signal source (like many sensors) from a load that would otherwise draw enough current to distort the source's own voltage -- useful for buffering, not for gain.

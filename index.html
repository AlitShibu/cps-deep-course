Before you start

How this site works

Every chapter page has the full course navigation on the left — click any topic to expand its chapters, click any chapter to jump straight there. Your reading progress (which chapters you've marked as read) is saved in this browser automatically, and the progress bar at the top always reflects the whole course, not just the current topic.

Topics still marked "soon" in the sidebar haven't been written yet — we're building this one topic at a time, in the order that makes sense for actually learning it, starting with the math you'll need before anything else clicks.

Keep every file in this same folder (including the assets folder) — the navigation and styling depend on files sitting next to each other, exactly like a real website's files do.

Vector Spaces, Basis & Rank

Chapters 1-4 kept hinting at this chapter without naming it: "span" (1.7), a matrix collapsing space (4.1), a system having infinite solutions (3.3) — these are all faces of the same underlying idea. This chapter names it properly and gives you the vocabulary (independence, basis, rank) to describe precisely how many independent directions a set of vectors — or a matrix — actually spans.

Section 5.1

Linear independence

Recall Section 1.7: the span of a set of vectors is every vector reachable via linear combinations of them. A natural follow-up question: does every vector in the set actually contribute a "new" direction, or is one of them redundant — already reachable from the others?

The definition

A set of vectors is linearly independent if no vector in the set can be written as a linear combination of the others. Equivalently (and this is the version you'll actually use to check it): the only way to combine them to get the zero vector is by using all-zero scalars.

c₁v₁ + c₂v₂ + ... + cₙvₙ = 0   has ONLY the solution c₁=c₂=...=cₙ=0
                                → linearly independent

If some OTHER combination (not all zero) also equals 0
                                → linearly dependent (redundant)
Two vectors pointing genuinely different directions vs. two vectors lying on the same line — only the first pair is independent.
Worked problem

Problem: Are v1 = (1, 2) and v2 = (2, 4) linearly independent?

Solution: Notice v2 = 2*v1 directly — v2 is just v1 stretched. Formally: solving c1*(1,2) + c2*(2,4) = (0,0), take c1=2, c2=-1: 2*(1,2) + (-1)*(2,4) = (2,4)+(-2,-4) = (0,0). A non-zero combination reaches zero, so they're linearly dependent — v2 contributes no new direction beyond what v1 already provides. Their span is just a single line, not the full 2D plane.

In NumPy — checking independence via rank (defined properly in 5.3)

import numpy as np
V = np.array([[1,2],[2,4]])   # vectors as rows
rank = np.linalg.matrix_rank(V)
print(rank)  # 1 — fewer than the 2 vectors given, confirming dependence
Section 5.2

Basis and dimension

What a basis is

A basis for a space is a set of vectors that is (a) linearly independent, and (b) spans the entire space. Together, these two conditions mean a basis is the smallest possible set of "building block" directions that can reach every point in the space, with no redundancy. The standard 2D basis is (1,0) and (0,1) — any 2D vector (x,y) is exactly x*(1,0) + y*(0,1), a unique combination.

Bases are not unique — a subtlety worth sitting with

The standard basis (1,0),(0,1) is the most familiar, but it's nowhere near the only valid basis for 2D space. (1,1) and (1,-1) also form a perfectly valid basis — they're independent (not multiples of each other) and together they can reach any 2D point via some combination. Different bases are just different "coordinate systems" for describing the exact same space — Chapter 6 (eigenvectors) and Chapter 7 (diagonalization) are, at their core, about finding a specially convenient basis for a given problem.

Dimension — how many basis vectors you need

Every basis for a given space has the same number of vectors — this number is called the dimension of the space. 2D space has dimension 2 (needs exactly 2 independent vectors as a basis, no more, no fewer); ordinary 3D space has dimension 3. This might feel obvious for space you can visualize, but it generalizes cleanly to spaces with far more dimensions than you can draw — a robot's full state space (position, velocity, joint angles) might be 12-dimensional, and "dimension" still means exactly the same thing: the number of independent directions needed to describe every possible state.

Worked problem

Problem: Do u = (1, 1, 0), v = (0, 1, 1), and w = (1, 2, 1) form a basis for 3D space?

Solution: Check independence first: does u + v = w? (1,1,0) + (0,1,1) = (1,2,1) — yes, exactly w. So w is redundant (a combination of u and v), meaning these three vectors are linearly dependent. Since a valid basis for 3D space needs exactly 3 independent vectors, and we only have 2 independent directions worth of information among these three, they do not form a basis for 3D space — they only span a 2D plane sitting inside 3D space.

Section 5.3

Rank — tying it all together

The definition

The rank of a matrix is the number of linearly independent rows (equivalently, independent columns — this equality is a real, non-obvious theorem, but it always holds). Practically: rank tells you the dimension of the space actually spanned by the matrix's columns — how many genuinely independent directions the matrix's output can reach.

The single fact this whole chapter has been building toward

A square n×n matrix is invertible exactly when its rank equals n — "full rank." This is the same fact as "non-zero determinant" (Chapter 4) and "linearly independent columns" (Section 5.1), viewed from a third angle: an invertible matrix doesn't collapse any dimension, so all n of its columns remain independent, spanning the full n-dimensional output space. A matrix with rank less than n is exactly the "information-destroying collapse" described back in Section 4.1 — now you have precise vocabulary (rank) for exactly how much it collapses, not just whether it does.

FactChapter it first appeared
Zero determinant → not invertibleChapter 4
System has infinite solutions → redundant equation (0=0 during elimination)Chapter 3
Vectors linearly dependent → one contributes no new directionSection 5.1
Rank < n → matrix isn't full rank, isn't invertibleSection 5.3 (this section)

These are four descriptions of exactly the same underlying phenomenon. Recognizing that they're the same fact — not four separate rules to memorize — is the single biggest "it finally clicked" moment most people have in a first linear algebra course.

Worked problem — connecting rank back to Chapter 3's solution types

Problem: A system Ax = b has a 3×3 coefficient matrix A with rank 2 (not full rank). What does this immediately tell you about the possible solutions, without doing any elimination?

Solution: Since rank(A) = 2 < 3, A is not invertible — its columns don't span the full 3D space, meaning A's transformation collapses one dimension. This means the system cannot have a unique solution: depending on whether b happens to lie within the reduced (2D) space A can actually reach, the system has either no solution (b is unreachable) or infinitely many solutions (b is reachable, but multiple different x vectors map to it, since a dimension's worth of information was lost). This is exactly why professional numerical code checks a matrix's rank before attempting to solve or invert — a low rank is an early, cheap warning that a system needs different handling.

In NumPy

import numpy as np
A = np.array([[1,2,3],[2,4,6],[1,0,1]])  # row 2 is 2x row 1 -- clearly dependent
print(np.linalg.matrix_rank(A))  # 2, not 3 -- confirms not full rank
print(np.linalg.det(A))          # 0.0 -- confirms not invertible, consistent with Chapter 4
Wrap-up

Recap

  1. A set of vectors is linearly independent if none of them is reachable as a combination of the others — checked by confirming the only way to combine them into the zero vector uses all-zero scalars.
  2. A basis is a linearly independent spanning set — the minimal set of "building block" directions needed to reach every point in a space; bases are not unique, but every valid basis for a given space has the same size.
  3. Dimension is that shared size — how many independent directions a space genuinely has.
  4. Rank of a matrix is the number of independent rows/columns — the dimension of the space its columns actually span.
  5. The unifying insight of this chapter: zero determinant, non-invertibility, linear dependence, less-than-full rank, and a system having no-unique-solution are all the same underlying fact — a matrix collapsing space onto a lower dimension — described from five different angles across Chapters 3-5.
Check yourself

Quick check

Question 1

What two conditions must a set of vectors satisfy to be called a basis for a space?

Linear independence (no redundant vectors) and spanning the whole space (every vector in the space is reachable as a combination of them).
Question 2

A 4x4 matrix has rank 3. Is it invertible? What does its rank tell you about the dimension of the space its columns span?

Not invertible — a 4x4 matrix needs full rank 4 to be invertible. Its columns span only a 3-dimensional subspace, not the full 4-dimensional space, meaning one dimension's worth of information is lost in the transformation.
Question 3

Name three different-sounding facts from Chapters 3-5 that are secretly describing the exact same underlying phenomenon.

Any three of: zero determinant, matrix not invertible, linearly dependent columns, less-than-full rank, or a system Ax=b having no unique solution — all describe a matrix collapsing space onto a lower dimension.

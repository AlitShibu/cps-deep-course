Signal Classification & Basic Operations

Everything a cyber-physical system does starts with a signal: a voltage from a sensor, a stream of ADC readings, a PWM command going out to a motor. This chapter builds the vocabulary the rest of the topic depends on — what a signal is, how continuous-time and discrete-time signals differ, the handful of elementary signals every other signal can be built from, how to shift, scale and flip a signal without making the classic mistakes, and how to measure a signal's size with energy and power.

Chapter 1 of 7Builds on: basic calculus, Basic Electronics Ch. 4 (sinusoids)Leads into: system properties (Ch. 2), convolution (Ch. 3)
Section 1.1

Continuous vs. discrete-time signals

A signal is a function that carries information — a quantity that varies with some independent variable, most often time. The reading of a temperature sensor as it changes through the day, the voltage on a microphone, the sequence of numbers your ESP32's ADC produces, the angle of a motor shaft: all signals. Mathematically, a signal is just a function, and the first classification that matters is what kind of domain that function lives on.

Continuous-time signals — x(t)

A continuous-time (CT) signal is defined for every real value of time t. You can ask for its value at t = 2, at t = 2.0001, at t = √2. It is written with round brackets: x(t). Physical quantities — the voltage across a capacitor, the position of a robot arm — are naturally continuous-time.

Discrete-time signals — x[n]

A discrete-time (DT) signal is defined only at integer values of an index n — it is a sequence of numbers. It is written with square brackets: x[n]. The value x[3] exists; x[3.5] does not exist at all. Anything a microcontroller stores or computes is discrete-time: an array of samples is literally a discrete-time signal.

x[1.5] is undefined — it is not zero

A discrete-time signal has no value between its integer indices. Students sometimes read x[n] as "a signal that happens to be zero between samples" — that is a different object. The brackets are a reminder: n must be an integer, and asking for x[1.5] is as meaningless as asking for element 1.5 of a C array.

Where discrete-time signals come from: sampling

The usual way a DT signal is born is by sampling a CT signal at a regular interval Ts (the sampling period), giving x[n] = x(nTs). The sampling frequency is fs = 1/Ts. This is exactly what an ADC does, and exactly what a control loop running every 10 ms does (Microcontrollers Ch. 3–4). Chapter 6 of this topic is devoted to what is lost — and what is not — when you do it.

Left: a continuous-time sinusoid defined at every instant. Right: the same signal sampled 8 times per second — a sequence of numbers indexed by integer n.

A second axis: analog vs. digital

"Continuous vs. discrete" describes the time axis. Independently, the amplitude axis can also be continuous or restricted to a finite set of levels:

Amplitude continuousAmplitude quantized
Time continuousAnalog signal (a sensor's raw voltage)Rare in practice (a staircase-like waveform)
Time discreteSampled-data signal (the idealized samples used in theory)Digital signal (what the ADC actually hands your code: a 12-bit integer every Ts)

Most of this topic works with the idealized "discrete time, continuous amplitude" case, because quantization is a separate, smaller effect (an ADC's resolution) that can be analyzed on its own.

Other ways to classify signals

Periodic vs. aperiodic. A CT signal is periodic if x(t + T) = x(t) for all t, for some T > 0; the smallest such T is the fundamental period. A DT signal is periodic if x[n + N] = x[n] for all n, for some integer N > 0.

A sampled sinusoid is not automatically periodic

A CT sinusoid cos(ω0t) is always periodic, with period 2π/ω0. The DT sinusoid cos(ω0n) is periodic only if 2π/ω0 is a ratio of integers, because the period N must itself be an integer number of samples. cos(πn/4) has period 8. But cos(n) — the CT signal cos(t) sampled at Ts = 1 — has ω0 = 1, and 2π/1 is irrational, so the sequence never repeats exactly, even though the underlying continuous signal is perfectly periodic. This surprises almost everyone the first time, and it is a preview of the sampling chapter: sampling can change the character of a signal.

Even vs. odd. x(t) is even if x(−t) = x(t) (mirror-symmetric about t = 0, like cosine) and odd if x(−t) = −x(t) (like sine). Every signal can be split uniquely into an even and an odd part:

x_e(t) = [ x(t) + x(−t) ] / 2
x_o(t) = [ x(t) − x(−t) ] / 2
x(t)   = x_e(t) + x_o(t)

Check with x(t) = et: the even part is (et + e−t)/2 = cosh t and the odd part is sinh t. This decomposition reappears in Chapter 4 (a Fourier series of an even signal contains only cosines).

Deterministic vs. random. A deterministic signal is fully specified by a formula or table; a random signal (sensor noise, for example) can only be described statistically. This topic treats deterministic signals; noise enters later, in estimation and filtering courses.

Section 1.2

The elementary signals

A small family of simple signals acts as the alphabet of the whole subject. Complicated signals are built from them, and — more importantly — a system's behavior is usually understood by seeing how it reacts to them. Learn these until you can sketch each one without looking.

The unit step

CT:  u(t) = 1 for t > 0,   0 for t < 0
DT:  u[n] = 1 for n ≥ 0,   0 for n < 0

The step models "switch turned on at t = 0" — a setpoint change, a power rail coming up. Control Systems Ch. 3 measured a system's step response; this is that input.

The unit impulse

In discrete time the impulse is simple and unambiguous:

δ[n] = 1 for n = 0,   0 otherwise

In continuous time, δ(t) is more subtle: it is an idealized pulse with zero width, infinite height, and total area exactly 1. It is defined by what it does inside an integral rather than by a value at t = 0:

∫ δ(t) dt = 1        and        ∫ x(t) δ(t − t₀) dt = x(t₀)     (the sifting property)
δ(t) is not "a function whose value at 0 is infinity"

You cannot evaluate δ(0) meaningfully. Treat δ(t) as the limit of ever-narrower, ever-taller pulses that always keep area 1 — the mathematical model of a very short, very sharp kick (a hammer strike, a switch glitch, a single ADC trigger). Everything you ever do with it happens under an integral, where it is perfectly well behaved.

Step and impulse are linked in a way you will use constantly:

DT:  δ[n] = u[n] − u[n−1]        u[n] = Σ δ[k]   (k from −∞ to n)
CT:  δ(t) = du/dt                 u(t) = ∫ δ(τ) dτ   (τ from −∞ to t)
The discrete impulse and step, and the continuous step. Note δ[n] = u[n] − u[n−1]: an impulse is the 'difference' of a step.

Why the impulse is the most important signal in this whole topic

Any DT signal can be written as a weighted sum of shifted impulses:

x[n] = Σ x[k] · δ[n − k]        (sum over all integers k)

Read that as: at each index k, put an impulse of height x[k]. Adding all of them reconstructs the signal exactly, because δ[n − k] is 1 only when n = k, so only the k = n term survives. This is the DT sifting property, and it is the single idea behind Chapter 3: if you know how a system responds to one impulse, and the system is linear and time-invariant, you know how it responds to every signal.

The ramp, the pulse, and the exponentials

SignalFormulaWhere you meet it
Rampr(t) = t·u(t)A steadily rising setpoint; the integral of the step
Rectangular pulsep(t) = u(t) − u(t − T)A PWM high interval; an enable window
Real exponentialx(t) = eat, DT: x[n] = aⁿDecay of an RC circuit (a < 0); runaway growth (a > 0)
SinusoidA cos(ωt + φ), ω = 2πfAC mains, vibration, any oscillation
Complex exponentialejωt = cos ωt + j sin ωtThe building block of the Fourier transform (Ch. 4–5)
Why the complex exponential shows up everywhere

By Euler's formula, ejωt packages a cosine and a sine into one object. It is not just notation: passing ejωt through a linear time-invariant system gives back the same ejωt multiplied by a complex constant. It is an eigenfunction of LTI systems — the same "eigen" idea as Linear Algebra Ch. 6, in a new setting. That property is why the Fourier transform works, and Chapter 5 is built on it.

Real exponentials and the sign of a

eat with a < 0 is a capacitor discharging: it decays toward zero, with time constant τ = 1/|a|. With a > 0 it blows up. In discrete time, aⁿ decays if |a| < 1, grows if |a| > 1, and alternates in sign if a < 0. Control Systems Ch. 3 tied pole locations to exactly these behaviors — you are now seeing the raw signals those poles produce.

Section 1.3

Shifting, scaling, reflecting

Almost every signal-processing manipulation is built from three operations on the independent variable: shifting, scaling, and reflecting. They are easy to state and remarkably easy to get wrong when combined.

The three operations, one at a time

OperationCTDTEffect
Time shiftx(t − t₀)x[n − k]t₀ > 0 delays the signal (moves it right)
Time scalingx(at)x[an] (integer a)|a| > 1 compresses, |a| < 1 stretches
Reflectionx(−t)x[−n]Mirrors the signal about t = 0
Amplitude scalingA·x(t)A·x[n]Changes height only, not timing
x(t − 2) moves the signal to the RIGHT

The minus sign fools people into thinking "shift left". Test it with a pulse: if x(t) has a feature at t = 0, then x(t − 2) has that feature where t − 2 = 0, i.e. at t = 2 — later in time. Subtracting a constant inside the argument delays the signal, which matches the physical picture: an output that arrives 2 seconds late is the original evaluated 2 seconds earlier.

A discrete-time example with actual numbers

Let x[n] be the sequence with x[0] = 1, x[1] = 2, x[2] = 3, x[3] = 4, and zero elsewhere.

SignalNon-zero valuesWhat happened
x[n]n = 0..3 → 1, 2, 3, 4original
x[n − 2]n = 2..5 → 1, 2, 3, 4delayed by 2 samples
x[−n]n = −3..0 → 4, 3, 2, 1mirrored: value at −n is x[n]
x[2n]n = 0..1 → 1, 3keeps only x[0], x[2] — samples are discarded

The last row is a genuine difference from continuous time: compressing a DT signal by an integer factor (downsampling) throws information away, and it cannot be undone. Stretching (x[n/2]) is only defined at even n and must be filled in with zeros or interpolated. This is why sampling-rate changes in embedded audio and sensor code are never free.

Combining operations: the x(at − b) trap

Suppose you need to sketch y(t) = x(2t − 3). Two orders of operations look plausible, and they give different answers. Use this reliable recipe:

1. Shift first:   v(t) = x(t − 3)         (replace t by t − 3)
2. Then scale:    y(t) = v(2t) = x(2t − 3)  (replace t by 2t in v)

The rule is: apply the shift to x, giving a new signal v; then treat v as the signal and scale its argument. Each step substitutes into the current function. Equivalently, rewrite the argument as 2(t − 1.5): scale first by 2, then shift by 1.5.

Compression by 2 halves the pulse width (2 → 1); the delay moves it. The pulse of x(2t − 3) is where 1 ≤ 2t − 3 ≤ 3, i.e. 2 ≤ t ≤ 3.
Verify by solving for where the pulse is "on"

x(t) equals 1 when 1 ≤ t ≤ 3. So y(t) = x(2t − 3) equals 1 when 1 ≤ 2t − 3 ≤ 3. Add 3: 4 ≤ 2t ≤ 6. Divide by 2: 2 ≤ t ≤ 3. This "solve the inequality on the argument" check works for any combination and is the safest way to confirm a sketch.

The wrong order, so you recognize it: scaling first gives w(t) = x(2t), a pulse on 0.5 ≤ t ≤ 1.5. Shifting that by 3 gives w(t − 3) = x(2(t − 3)) = x(2t − 6), a pulse on 3.5 ≤ t ≤ 4.5 — this is not x(2t − 3). Shifting w by 3 is not the same as shifting x by 3 inside the scaled argument.

Section 1.4

Signal energy and power

Two signals can both be "large" in very different ways. A single brief kick is large in total energy; a steady hum that never stops is large in average power. These two measures split all practical signals into two classes.

Energy

CT:  E = ∫ |x(t)|² dt     (t from −∞ to ∞)
DT:  E = Σ |x[n]|²        (n from −∞ to ∞)

The name comes from electronics: if x(t) is the voltage across a 1 Ω resistor, then |x(t)|² is the instantaneous power dissipated, and integrating it over time gives energy in joules. Squaring also makes positive and negative values both count as "size".

Power

CT:  P = lim(T→∞)  (1 / 2T) ∫ |x(t)|² dt     (t from −T to T)
DT:  P = lim(N→∞)  (1 / (2N+1)) Σ |x[n]|²    (n from −N to N)

Power is the average of |x|² over all time. For a periodic signal you do not need the limit — averaging over one period gives the same answer.

The two classes

ClassConditionConsequenceExamples
Energy signal0 < E < ∞P = 0A decaying exponential, a single pulse
Power signal0 < P < ∞E = ∞A sinusoid, a step, any non-decaying periodic signal

A signal cannot be both: finite energy spread over infinite time averages to zero power, and non-zero average power sustained forever adds up to infinite energy. Some signals (like the ramp) are neither.

Three calculations you should be able to do

Example A — decaying exponential (CT, energy signal)

x(t) = e−t u(t). Then E = ∫0∞ e−2t dt = [ −e−2t/2 ]0∞ = 0 − (−1/2) = 1/2. Finite, so it is an energy signal, and its power is 0.

Example B — sinusoid (CT, power signal)

x(t) = A cos(ω₀t + φ). Average |x|² over one period: P = A² · (average of cos²) = A²/2, because cos² averages to 1/2 over a period. So P = A²/2 regardless of frequency or phase. Its square root, A/√2, is the familiar RMS value: a 325 V-peak mains sine has 230 V RMS.

Example C — DT geometric signal (energy signal)

x[n] = (0.5)ⁿ u[n]. Then |x[n]|² = (0.25)ⁿ for n ≥ 0, and E = Σ (0.25)ⁿ = 1/(1 − 0.25) = 4/3 using the geometric series Σ rⁿ = 1/(1 − r) for |r| < 1. The unit step u[n], by contrast, has infinite energy but average power 1/2.

Why an embedded engineer cares

Power (as mean-square value) is what an RMS calculation on an ADC buffer computes — the standard way to measure vibration level, audio loudness, or motor current. Energy is what matters for a transient event: how much total "disturbance" a single glitch delivered. Choosing the wrong measure — using energy on a signal that never stops — gives infinity and a confusing result.

Section 1.5

Worked problem — sampling a sinusoid

Problem

A sensor produces the continuous-time signal x(t) = 3 cos(4πt), with t in seconds. An ADC samples it at fs = 8 Hz. (a) Write the discrete-time signal x[n]. (b) Find its fundamental period N. (c) Compute its power. (d) Repeat (a)–(b) for fs = 6 Hz. (e) What happens if the ADC samples x(t) = cos(t) at Ts = 1 s?

(a) T_s = 1/8 s, so x[n] = x(nT_s) = 3 cos(4π · n/8) = 3 cos(πn/2)

(b) ω₀ = π/2. Period requires ω₀N = 2πm for integer m:
    (π/2)N = 2πm  →  N = 4m.  Smallest positive integer: N = 4.
    Check the values: n = 0,1,2,3 → 3, 0, −3, 0, then repeats.

(c) Average of x[n]² over one period:
    (9 + 0 + 9 + 0) / 4 = 18/4 = 4.5
    Agrees with the CT formula A²/2 = 9/2 = 4.5.

(d) f_s = 6 Hz → x[n] = 3 cos(4πn/6) = 3 cos(2πn/3).
    ω₀ = 2π/3;  (2π/3)N = 2πm → N = 3m → N = 3.
    Power is still 9/2 (sampling a periodic signal at a
    regular rate does not change its average power).

(e) x[n] = cos(n). ω₀ = 1, and ω₀N = 2πm would need N = 2πm,
    which is never an integer (π is irrational).
    The sampled signal is NOT periodic, even though cos(t) is.

What this exercise shows: the same physical signal became a different-looking sequence at each sampling rate (period 4 samples at 8 Hz, period 3 samples at 6 Hz) but always represented the same 2 Hz oscillation — 4 samples at 8 Hz and 3 samples at 6 Hz each span exactly 0.5 s. Part (e) is a warning that DT periodicity is a property of the sequence, not of the underlying waveform. In Chapter 6 you will see what happens when fs is pushed too low relative to the signal's frequency.

Wrap-up

Recap

  1. A signal is a function carrying information. CT signals x(t) exist at every real time; DT signals x[n] exist only at integer indices. Sampling gives x[n] = x(nTs). Analog vs. digital is a separate axis describing amplitude.
  2. A DT sinusoid cos(ω₀n) is periodic only when 2π/ω₀ is rational; sampling a periodic CT signal does not guarantee a periodic sequence. Every signal splits into an even part and an odd part.
  3. The elementary signals: unit step, unit impulse (δ[n] is 1 at n = 0; δ(t) is defined by area 1 and the sifting property), ramp, pulse, real exponentials, sinusoids, and the complex exponential ejωt.
  4. Any DT signal is a sum of weighted, shifted impulses: x[n] = Σ x[k]δ[n − k]. This is the foundation of convolution in Chapter 3.
  5. x(t − t₀) delays by t₀; x(at) compresses when |a| > 1; x(−t) mirrors. For x(at − b), shift first then scale, and verify by solving the argument's inequality. DT downsampling discards samples.
  6. Energy E = ∫|x|²dt (finite for energy signals); power P is its time-average (finite for power signals). A sinusoid of amplitude A has P = A²/2; the two classes are mutually exclusive.
Check yourself

Quick check

Question 1

Why is x[1.5] meaningless for a discrete-time signal, and how is that different from saying it equals zero?

A DT signal is defined only at integer indices, so there is no value at 1.5 — the expression is undefined, like indexing a C array at 1.5. Saying it is zero would describe a different object, a signal that exists everywhere but happens to vanish between integers.
Question 2

If x(t) has a peak at t = 0, where is the peak of x(t − 4)? Of x(2t)? Of x(−t)?

x(t − 4): the peak occurs where t − 4 = 0, so at t = 4 (delayed). x(2t): the argument is 0 at t = 0, so the peak stays at t = 0 (only the width halves). x(−t): the argument is 0 at t = 0, so the peak also stays at t = 0 (the signal is mirrored).
Question 3

Compute the energy of x[n] = (0.5)ⁿ u[n]. Is it an energy signal or a power signal?

|x[n]|² = (0.25)ⁿ for n ≥ 0, so E = Σ (0.25)ⁿ = 1/(1 − 0.25) = 4/3. The energy is finite and non-zero, so it is an energy signal, and its power is 0.
Question 4

Why can cos(n) (in radians) never be a periodic DT signal, even though cos(t) is periodic?

Periodicity would require some integer N with N = 2πm for an integer m. Since π is irrational, no such integer pair exists. The DT period must be a whole number of samples, which a period of 2π seconds sampled every 1 second cannot be.
